# 模拟交易工作机制

> 关联总纲：`docs/全链路报告闭环体系.md`

---

## 一、定位

模拟交易是盘中策略的量化验证系统。5个cron分别在09:35、10:30、11:25、13:35、14:30运行，跟踪持仓模拟盈亏和信号触发情况。**不产生推送内容，只运行脚本记录数据。**

---

## 二、调度

- **时间**：09:35 / 10:30 / 11:25 / 13:35 / 14:30（交易日）
- **脚本**：通过 `openclaw cron edit` 配置的脚本任务
- **超时**：120秒
- **推送**：不推送（静默运行）
- **输出**：数据记录到日志，供15:30盘后审计引用

---

## 三、数据流

```
盘中监控每10分钟信号
       ↓
模拟交易每30-60分钟快照
   (持仓浮盈+信号触发次数)
       ↓
15:30盘后审计 ← 模拟交易收盘报告(15:10)
  用模拟数据验证当日交易策略
```

---

## 四、自律规则

- 模拟交易数据是系统推算，不是用户实际交易记录
- 收盘审计中必须标注"系统建议"和"用户执行"的区别
