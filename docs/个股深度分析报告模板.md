# 个股深度分析报告模板 v2.0

> 适用于：任意标的深度研判。分析结论可直接嵌入盘前作战/竞价验证/午间修正/盘后审计/结构重塑/信息炼金等定时报告。
> 原则：先说结论再拆逻辑，多下判断少堆表格，自然语言有温度。基本面+技术面+形态信号三维交叉验证。

### 主营业务

### 基本面与业绩

按兆易报告的写法，一段话说清楚——**最新季度营收xxx亿（同比±xx%），净利润xxx亿（同比±xx%）**。毛利率xx%、净利率xx%，盈利能力在行业中属于什么水平。机构一致预期全年净利润xxx亿，对应EPS xxx元。

重点数字用**加粗**标出来，不要全篇一样粗细。

### 估值

PE xx倍，对于xx%增速的标的来说估值合理/偏高/低估。可比公司平均PE xx倍，历史分位xx%。一句话定调。

### 核心催化

一段话：该标的目前最大的基本面催化剂是什么——产业趋势节点（存储周期+xx IPO）、政策落地（xx补贴）、订单放量（xxx合同）、还是重组预期。把逻辑链条写清楚：A发生→B受益→C对股价意味着什么。

参考你兆易报告的写法——"长鑫半年净利500-570亿，按行业PE 100倍给估值=10万亿级——不管这个估值是否合理，存储芯片板块的估值天花板被打开了。兆易作为A股存储芯片最纯标的之一，资金会优先对标。" 是这种逻辑推进的写法，不是简单说"利好"。

### 机构与资金态度

近3月研报覆盖（买入x家/增持x家），最新目标价¥xxx（空间±xx%）。**股东层面：** 实控人大股东增减持动向（如有列出具体减持日期/均价/金额）、融资余额变化、股东人数变化（散户化/机构化趋势）。
