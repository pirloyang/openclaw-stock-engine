# 全链路报告闭环体系（总纲）

> 本文件是 Framework v2.0（《预测分析行为准则》）的具体化与操作化。所有定时报告、盘中监控、模拟交易均遵循此框架。

---

## 一、核心原则

### 1.1 连续剧逻辑（Framework v2.0 第1条）

7份报告不是孤立的——它们是同一部连续剧的7集。每份报告必须：

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  08:30      │ ──→  │  09:25      │ ──→  │  12:00      │
│  盘前作战    │      │  竞价验证    │      │  午间修正    │
└─────────────┘      └─────────────┘      └─────────────┘
      ↑                                        │
      │                                        ↓
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  22:00      │ ←──  │  21:00      │ ←──  │  15:30      │
│  信息炼金    │      │  结构重塑    │      │  盘后审计    │
└─────────────┘      └─────────────┘      └─────────────┘
```

**每份报告开头**必须用一段话引用上一份报告的核心结论，并点明"这个判断在今天得到了验证/挑战——"然后引出本报告。

**每份报告结尾**必须预告下一份报告的方向（"上述信号已记录，将纳入XX报告的策略评估"）。

**核心判断必须迭代递进**，不能简单重复上一份的结论。

### 1.2 盘中 vs 盘后严格分离（Framework v2.0 第6条）

| 维度 | 盘中监控 | 盘后报告 |
|------|---------|---------|
| 时间 | 09:35~14:55 每10分钟 | 15:30 / 21:00 / 22:00 |
| 内容 | 实时行情、异动信号、即时操作 | 绩效审计、复盘分析、策略推演 |
| 推送触发 | 有信号才推（全池安静则NO_REPLY） | 定时自动推送 |
| 推送要素 | 判断依据+买卖价格+操作指令+止损价+解盘 | 引用链+持仓审计+明日策略 |
| 风格 | 短、快、直接 | 深度、完整、前后呼应 |

**严禁：** 将盘中的实时交易信号混入盘后报告中，也不得将复盘分析塞入盘中监控推送。

### 1.3 数据纪律（Framework v2.0 第4条）

- 持仓数据 **仅以 TOOLS.md 为准**，脚本输出中的止损/买入/卖出信号是系统建议，不是用户交易记录
- 推送信号时说"XX触发XX条件"，不说"你卖了XX/你买了XX"
- 每日15:30盘后审计后，如TOOLS.md有更新，同步修正持仓基线

### 1.4 8条自查清单（Framework v2.0 第8条）

每份报告发出前执行：
1. ✅ 是否引用了上一份报告的核心结论？
2. ✅ 是否预告了下一份报告的方向？
3. ✅ 持仓数据是否从TOOLS.md读取（非硬编码）？
4. ✅ 是否区分了"系统建议"和"用户交易"？
5. ✅ 已清仓标的未出现？
6. ✅ 核心判断是否与前面报告迭代递进而非简单重复？
7. ✅ 是否有明确的结论/操作建议而非纯数据堆砌？
8. ✅ 是否有至少一个具体的操作指令（持仓方向）或机会扫描（新标的）？

## 三、报告通用模板（每份报告必须包含）

### 3.1 开头引用段
> 📋 **上一份报告核心结论：** [引用上一份的一句话核心判断]
> 🕛 **验证/挑战：** [这个判断在今天验证/被挑战了——点明变化引出本报告]

### 3.2 持仓审计（15:30/21:00）
逐只一句：操作结论 → 仓位控制 + 介入价 → 后续策略 → 分析

### 3.3 新机会扫描（22:00）
四个步骤：识别事件 → 判断映射链 → 筛选标的（确定性>弹性） → 入库监控

### 3.4 结尾预告段
> 📌 **上述[XX信号/策略]已记录，将纳入[下一份报告名称]的[XX方面]评估。**

## 四、行为规则（Framework v2.0 第7条）

- **T+1铁律**：当日买入的T+1才能卖出，盘中不得建议当日做T
- **-5%硬止损**：任何持仓跌破成本-5%自动触发止损评估
- **单票20%上限**：单只持仓不超过总仓位的20%
- **总仓位80%上限**：总投入不超过可用资金的80%
- **禁止追涨**：单日涨幅超过5%的标的当日不加仓
- **MA5偏离>5%禁止加仓**：股价高于MA5超过5%时不宜加仓
- **MA20偏离>30%禁止买入**：股价高于MA20超过30%时不宜新开仓
- **该涨不涨/该跌不跌**：有利好不涨→警惕，有利空不跌→关注
