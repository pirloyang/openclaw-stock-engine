## 维护规则

- **新增规则文件** → 必须在本目录登记 + 在对应 cron prompt 引用
- **修改现有规则** → 必须升级版本号 + 同步本目录版本
- **禁止 AI 自主修改** 任何规则文件或本目录，必须辉哥确认

## 版本说明
- v1.0 = 初版生效
- vN.X = 主版本升级（结构性变化）
- vN.X.Y = 小修订（条款增减、笔误修正）

## 引用约定
- cron prompt 引用规则用：`exec cat /root/.openclaw/workspace/docs/<文件名>.md`
- 报告内引用规则用：`（《XX规则》Rn）`
- 风控自检区块统一用：`【风控自检 · 风控规则 v1.0】`
