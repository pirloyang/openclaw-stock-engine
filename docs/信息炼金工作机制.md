# 信息炼金工作机制 v1.0

**生效日期：** 2026-06-06
**适用 cron：** 信息炼金（22:00 生成 + 22:10 推送）
**配套文件：** `docs/信息炼金报告模板.md`

> **核心定位：** 信息炼金是每日 22:00 的"明日弹药库"——把当晚的外部消息、研报、产业动态、信号引擎结论炼成可操作的明日清单，是 08:30 盘前作战的必读上游。

---

## 一、报告角色与上下游

### 上游输入
| 数据源 | 用途 |
|---|---|
| `TOOLS.md` 持仓节 | 持仓权威列表（《风控规则》R12）|
| `stock-signals/focus_watchlist.json` | 重点关注清单 |
| `/tmp/stock_alerts/signals_summary.json` | 引擎信号摘要（R11 依据）|
| `/tmp/stock_alerts/L1/L4/L3/L6.txt` | 大盘/板块/重点/热点 |
| web_search（5 个固定 query）| 外部消息+研报+产业动态 |

### 下游消费
- **次日 08:30 盘前作战**：第 1 步必读"昨晚信息炼金报告"
- **22:10 推送 cron**：读取报告全文转发到微信

---

## 二、运行机制

### 时间窗口
- **22:00** 生成 cron 启动，超时 600s
- **22:10** 推送 cron 启动，读取 22:00 生成的报告并转发

### 执行步骤
```
1. 加载规则文件（《风控规则》《重点关注清单》《信号引擎手册》）
2. SOP-M3 一致性校验（TOOLS.md ↔ focus_watchlist hold 状态）
3. 5 个固定 web_search（A股收盘/美股/政策/研报/有色金属）
4. 读取 /tmp/stock_alerts/ 全套分层数据
5. 读取 docs/信息炼金报告模板.md
6. 按模板七节生成（外部消息扫描/风口事件/研报萎取/标的交叉验证/产业数据/明日日程/监控清单更新）
7. write 保存到 reports/YYYY-MM-DD-2200-信息炼金.md
8. 输出报告正文（供推送 cron 转发）
```

### 推送链路（22:10）
```
exec cat reports/YYYY-MM-DD-2200-信息炼金.md
  ↓
推送到辉哥微信
  ↓
失败 → failureAlert → 重试一次 + 告警
```

## 三、内容规则

### C1 · 外部消息可信度
- **优先级：** web_search 结果 > 本地缓存 > AI 知识库
- **历史教训：** 06-03 发现 SearXNG 从未安装，AI 曾把训练数据当成"实时搜索结果"
- 报告中所有外部消息必须能从 web_search 输出中追溯

### C2 · 标的交叉验证（第四节）
- 必须覆盖：当前所有 hold=true 持仓 + status="重点监控" 标的
- 信号引擎列必须引用《信号引擎规则手册》中的规则名+strength
- 引擎看空时（《风控规则》R11）操作建议不得乐观

### C3 · 明日关键日程（第六节）
- 仅列出 **明日交易日内已确定** 的事件（解禁/财报/重要政策窗口/数据发布）
- 不写"可能"、"预计"、"传闻"类不确定信息

### C4 · 监控清单更新（第七节）
- 若发现新候选标的 → 写入 `fengkou_candidates.json`，**不直接加入 focus_watchlist**（依《重点关注清单维护规则》A3）
- 第七节"执行检查"至少包含：
  - ✅ signals_summary.json 引擎信号已与持仓全量交叉验证
  - ✅ TOOLS.md 与 focus_watchlist 一致性已检验

---

## 四、自律规则

| 规则 | 说明 |
|---|---|
| R1 | 持仓以 TOOLS.md 为准 |
| R2 | 已清仓标的不得出现 |
| R3 | 信号引擎看空时不得给相反推荐（《风控规则》R11）|
| R4 | web_search 结果优于本地数据 |
| R5 | 报告必须 write 到 reports/YYYY-MM-DD-2200-信息炼金.md |
| R6 | 报告末尾必输出风控自检区块（《风控规则》R16）|

---

## 五、失败处理

| 失败模式 | 处理 |
|---|---|
| web_search 全部失败 | 报告标注"⚠️ 外部消息源不可用"，仅基于本地数据生成 |
| signals_summary.json 缺失 | 报告标注"⚠️ 信号引擎数据陈旧"，跳过第四节交叉验证 |
| TOOLS.md 解析失败 | 阻断报告生成，触发 failureAlert |
| 22:00 cron timeout | failureAlert → 辉哥微信告警 |
| 22:10 推送失败 | failureAlert → 重试一次 |
