# 月度绩效审计规则 v1.0

**生效日期：** 2026-06-06
**适用 cron：** 月度绩效审计-月末自动生成（每月 28-31 日 18:00）
**核心脚本：** `scripts/monthly_review.py`
**数据源：** `data/investment_goals.json`、`data/portfolio_history.json`、`data/monthly_snapshot.json`

> **核心定位：** 月度审计是季度/年度复盘的基础单元，聚合 4-5 份周复盘，对照里程碑目标产出结构化月报。

---

## 一、运行机制

### 触发条件
- **每月 28-31 日 18:00**（cron 表达式 `0 18 28-31 * *`）
- `monthly_review.py` 内部判断"今日是否本月最后一个交易日"
  - 是 → 生成报告
  - 否 → 静默退出，cron 回复 HEARTBEAT_OK

### 执行步骤
```
1. 加载 data/investment_goals.json（目标基线）
2. 加载 data/portfolio_history.json（净值时间序列）
3. 解析当月所有交易日的净值
4. 聚合本月 reports/weekly/ 下所有周复盘
5. 计算月度指标（见 §二）
6. 对照里程碑目标计算进度
7. 写 reports/monthly/YYYY-MM.md
8. 写 data/monthly_snapshot.json（结构化数据供下月对比）
9. cron 读取月报推送辉哥
```

## 二、月度指标定义（强制）

### M1 · 净值指标
| 指标 | 计算 |
|---|---|
| 月初净值 | 当月第一个交易日开盘前快照 |
| 月末净值 | 当月最后一个交易日收盘后快照 |
| 月度收益率 | (月末 - 月初) / 月初 × 100% |
| 月内最大回撤 | max((peak - trough) / peak) × 100% |
| 月内最大盈利 | max((peak - trough) / trough) × 100% |
| 已结盈亏 | 当月所有清仓事件盈亏之和 |
| 浮动盈亏 | 月末持仓浮动盈亏 |

### M2 · 操作指标
| 指标 | 来源 |
|---|---|
| 本月交易次数（清仓数）| TOOLS.md "今日清仓记录" 节聚合 |
| 胜率 | 盈利清仓数 / 总清仓数 |
| 平均盈利 | 盈利清仓的平均盈亏% |
| 平均亏损 | 亏损清仓的平均亏损% |
| 盈亏比 | 平均盈利 / |平均亏损| |
| 最大单笔盈利 | TOP1 清仓 |
| 最大单笔亏损 | BTM1 清仓 |

### M3 · 风控指标
| 指标 | 说明 |
|---|---|
| R2 止损执行率 | 触止损线的标的中按 R2 执行的比例 |
| R3 单票合规率 | 月内最大单票占比 vs 20% 上限 |
| R7 总仓位合规率 | 月内总仓位在 60-80% 区间的天数比例 |
| R11 信号一票否决合规率 | 月内信号看空但仍加仓的次数（应为 0）|

### M4 · 里程碑进度
- 当前净值 vs 当前里程碑目标（数据来自 investment_goals.json）
- 时间进度（已用时 / 总时间）
- 净值进度（已增长 / 目标增长）
- 进度差距（净值进度 - 时间进度）
  - > +10% → 🟢 超额完成
  - -10% ~ +10% → 🟡 基本同步
  - < -10% → 🔴 严重落后

## 三、报告结构（强制）

```
# YYYY-MM 月度绩效审计

## 一、净值总览
（M1 表格）

## 二、操作统计
（M2 表格 + 本月清仓明细 TOP5 + BTM5）

## 三、风控合规
（M3 表格 + 违规事件清单）

## 四、里程碑进度
（M4 + 当前所处里程碑 + 距离下一里程碑差距）

## 五、本月最佳/最差交易复盘
- 最佳：标的 + 决策路径 + 盈利原因
- 最差：标的 + 决策路径 + 亏损原因 + 教训

## 六、下月策略调整建议
- 仓位策略
- 标的调整
- 风控强化

## 七、风控自检
（《风控规则》R16 完整 6 项）
```

## 四、自律规则

| 规则 | 说明 |
|---|---|
| R1 | 所有数据从结构化文件读取，禁止凭记忆 |
| R2 | 里程碑进度对照 investment_goals.json，不得自己估算目标值 |
| R3 | 违规事件必须如实列出，不得隐藏（R11 违规、R3 超限等）|
| R4 | 报告 write 到 reports/monthly/YYYY-MM.md |
| R5 | monthly_snapshot.json 必须更新（下月对比依赖）|
| R6 | 末尾必输出风控自检（R16）|

---

## 五、失败处理

| 失败模式 | 处理 |
|---|---|
| portfolio_history.json 缺失 | 阻断生成，触发 failureAlert |
| investment_goals.json 缺失 | 跳过 M4，标注"⚠️ 目标基线缺失" |
| 当日非月末交易日 | 静默退出，cron 回复 HEARTBEAT_OK |
| cron timeout | failureAlert |

---

## 六、维护

- `investment_goals.json` 修改需辉哥确认，AI 不得自主调整目标值
- `monthly_review.py` 指标算法变更需同步更新本规则
- **禁止 AI 自主修改本文件**
