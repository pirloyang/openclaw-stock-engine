# 信号回测验证规则 v1.0

**生效日期：** 2026-06-06
**适用 cron：** 信号回测-月末（每月最后一个交易日 19:00）
**核心脚本：** `scripts/signal_backtest.py`
**配套数据：** `data/signal_backtest_history.json`

> **核心定位：** 解决"信号引擎共振判定从未被回测"的根本性盲区。每月对历史推荐做事后胜率统计，发现真实表现偏离期望时自动告警，触发权重调整讨论。

---

## 一、回测目标

回答三个问题：

1. **三重共振推荐的真实胜率是多少？** 是否如规则手册预期 ≥ 70%？
2. **双重确认的胜率是多少？** 是否 ≥ 55%？
3. **单一信号的胜率是多少？** 是否 ≥ 50%？

若任一档跌破期望 10 个百分点以上，触发**信号权重调整讨论**——AI 不得自主修改，但必须主动提醒辉哥。

---

## 二、数据采集

### 上游数据
- `reports/` 下所有日报告（盘前作战、盘后审计、结构重塑、信息炼金）
- `/tmp/stock_alerts/signals_summary.json` 历史快照（如有）
- `data/portfolio_history.json`（持仓 + 价格历史）

### 采集逻辑
扫描过去 30 个交易日的报告，正则提取：
- "三重共振-出手"标的及推荐价
- "双重确认-观望"标的
- "单一信号-弱观察"标的
- "看空-减仓"标的（验证空头信号胜率）

每条记录格式：
```json
{
  "date": "2026-05-15",
  "code": "603583",
  "name": "捷昌驱动",
  "signal_class": "triple_resonance",  // triple_resonance | dual_confirm | single | bearish
  "recommend_price": 28.50,
  "source_report": "2026-05-15-2200-信息炼金.md"
}
```

## 三、胜率计算

### W1 · 跟踪窗口
- **T+5**（5 个交易日后）
- **T+10**（10 个交易日后）
- **T+20**（20 个交易日后）

### W2 · 胜率口径

**多头信号（triple_resonance / dual_confirm / single）：**
- 命中条件：T+N 收盘价 / 推荐价 ≥ 1.03（涨幅 ≥ 3% 视为命中）
- 胜率 = 命中数 / 总推荐数

**空头信号（bearish / suspend_all_buy）：**
- 命中条件：T+N 收盘价 / 推荐时价 ≤ 0.97（跌幅 ≥ 3% 视为命中）
- 胜率 = 命中数 / 总信号数

### W3 · 期望胜率（拍板基线）

| 信号类别 | T+5 期望 | T+10 期望 | T+20 期望 |
|---|---|---|---|
| **三重共振** | ≥ 65% | ≥ 70% | ≥ 60% |
| **双重确认** | ≥ 55% | ≥ 55% | ≥ 50% |
| **单一信号** | ≥ 50% | ≥ 50% | ≥ 45% |
| **空头信号** | ≥ 60% | ≥ 65% | ≥ 55% |

## 四、告警与触发

### A1 · 自动告警
胜率低于期望基线 ≥ 10pp 时：
- 推送辉哥微信
- 写入 `reports/monthly/YYYY-MM-signal-backtest.md`
- 同时记入 `data/signal_backtest_history.json` 历史归档

### A2 · 告警示例
```
🔴 信号引擎回测告警 · YYYY-MM

【问题信号】三重共振 T+10 胜率仅 52%（期望 ≥ 70%，缺口 -18pp）
【样本量】本月 N 个三重共振推荐
【低胜代表性标的】
- XXX (XXXXXX) T+10 下跌 8.5%
- YYY (YYYYYY) T+10 下跌 5.2%
- ZZZ (ZZZZZZ) T+10 下跌 4.0%
【可能根因】
- 板块切换：本月科技推荐过密
- 权重失衡：均线信号权重过高，未考虑大盘环境
【建议动作】
1. 辉哥审阅是否需要调整《信号引擎规则手册》共振判定权重
2. 评估是否引入"大盘环境过滤"权重项
3. 暂停三重共振信号 7 天观察期 (可选)
```

### A3 · 调整流程
- AI **不得**自主修改信号脚本或权重
- 必须由辉哥**显式确认**后才能调整
- 调整后下个月继续回测验证

## 六、自律规则

| 规则 | 说明 |
|---|---|
| R1 | 回测数据从历史报告提取，不得伪造 |
| R2 | 期望胜率（W3 表）不得自主修改 |
| R3 | 告警必须如实推送，不得隐藏低胜率 |
| R4 | 信号权重调整必须辉哥确认 |
| R5 | 月度审计强制包含第八节，缺失视为合规违规 |

---

## 七、失败处理

| 失败模式 | 处理 |
|---|---|
| 历史报告残缺 | 报告标注"⚠️ 样本量不足"，记入 history |
| 价格数据缺失 | 当条记录标 "no_data"，不计入胜率 |
| 当月样本 < 10 | 跳过当月，标注 "样本不足" |
| cron timeout | failureAlert |
