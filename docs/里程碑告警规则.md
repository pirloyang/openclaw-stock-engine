# 里程碑告警规则 v1.0

**生效日期：** 2026-06-06
**适用 cron：** 里程碑告警-每日收盘检查（15:35）
**核心脚本：** `scripts/milestone_alert.py`
**数据源：** `data/investment_goals.json`、`data/milestone_status.json`

> **核心定位：** 每日收盘后对账户进度做体检，进度严重偏离里程碑目标时主动告警辉哥，避免温水煮青蛙。

---

## 一、告警阈值定义

### A1 · 时间进度 vs 净值进度
| 偏离程度 | 阈值 | 告警动作 |
|---|---|---|
| 净值进度 < 时间进度 - 10% | 严重落后 | 🔴 推送告警 |
| 净值进度 < 时间进度 - 5% | 轻度落后 | 🟡 推送告警 |
| 净值进度 -5% ~ +10% | 基本同步 | 静默（HEARTBEAT_OK）|
| 净值进度 > 时间进度 + 10% | 超额完成 | 🟢 推送鼓励 |

**计算口径：**
- 时间进度 = (今日 - start_date) / (deadline - start_date)
- 净值进度 = (当前净值 - initial_capital) / (target_value - initial_capital)

### A2 · 单日大幅回撤
| 单日跌幅 | 告警动作 |
|---|---|
| 总净值单日跌 > -3% | 🔴 推送告警 + 复盘提醒 |
| 总净值单日跌 -2% ~ -3% | 🟡 推送提醒 |
| < -2% | 静默 |

### A3 · 累计回撤
| 累计回撤（vs 历史最高）| 告警动作 |
|---|---|
| 累计回撤 > -15%（达到 risk_rules.max_total_drawdown_pct）| 🔴 强制告警 + 降仓建议 |
| 累计回撤 -10% ~ -15% | 🟡 告警 + 减仓评估 |
| -5% ~ -10% | 静默 |

### A4 · 里程碑临近告警
| 距离里程碑 deadline | 当前进度 | 告警动作 |
|---|---|---|
| 7-30 天 | < 80% | 🟡 提醒"距离 XXX 里程碑剩 N 天，进度仅 X%" |
| < 7 天 | < 95% | 🔴 强制告警 + 加速建议 |
| < 7 天 | ≥ 95% | 🟢 鼓励"即将达成 XXX 里程碑" |

## 二、告警去重规则

### D1 · 同类告警冷却
- 同一告警类型 24h 内仅推送一次
- 由 `data/milestone_alerts.json` 记录最近推送时间戳
- 例外：A2 单日大幅回撤每个交易日独立判断

### D2 · 告警升级
- 同一告警连续 3 天未消除 → 升级为"⚠️ 持续告警"，强制推送
- 升级后再连续 5 天未消除 → 增加"建议人工评估"

## 三、告警消息格式

### 格式标准
```
🔴/🟡/🟢 里程碑告警

【类型】<时间进度落后 / 单日回撤 / 累计回撤 / 里程碑临近>
【当前状态】<具体数值>
【目标基线】<对比目标>
【建议动作】<可执行建议，含风控规则索引>
【触发时间】YYYY-MM-DD HH:MM
```

### 示例
```
🔴 里程碑告警

【类型】时间进度落后
【当前状态】净值 ¥87,500，进度 21% / 时间进度 38%
【目标基线】"清淤收官"里程碑 deadline 2026-07-31，目标 ¥100,000
【建议动作】
1. 检查当前持仓质量（《风控规则》R11 信号一票否决）
2. 评估是否切换至更高弹性标的
3. 仓位提升至 70-80%（当前 X%）
【触发时间】2026-06-06 15:35
```

## 四、自律规则

| 规则 | 说明 |
|---|---|
| R1 | 告警阈值不得自主修改，需辉哥确认 |
| R2 | 净值数据从 portfolio_engine.compute_net_worth 读，不得估算 |
| R3 | 告警建议必须含具体可执行动作，不得只描述问题 |
| R4 | 告警建议必须符合《交易风控规则》R1/R2/R3/R10/R11 |
| R5 | 无告警时静默（HEARTBEAT_OK），不打扰 |
